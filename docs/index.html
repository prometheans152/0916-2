🗺️ 台灣六大分區氣溫預報地圖

🌡️ 均溫分級色階圖例 (Daily AvgT Color Legend)：
🔵 < 20°C (低溫 / Blue) 🟢 20–25°C (舒適 / Green) 🟡 25–30°C (溫暖 / Yellow) 🔴 > 30°C (炎熱 / Red)
公式：AvgT = (MinT + MaxT) / 2；分界標準：<20°C（藍）、20°C ≤ AvgT < 25°C（綠）、25°C ≤ AvgT ≤ 30°C（黃）、>30°C（紅）。

📍 說明：各分區標記顏色嚴格由當日平均氣溫 AvgT = (MinT + MaxT) / 2 之四級色階驅動；較大且具備深色外環之標記點為當前下拉選單所選之分區。座標點為代表性中心參考座標（北部: 臺北、中部: 臺中、南部: 高雄、東北部: 宜蘭、東部: 花蓮、東南部: 臺東），非行政邊界邊線。
